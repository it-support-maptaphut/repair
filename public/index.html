คู่มือการใช้งานระบบแจ้งซ่อม

1. ผู้ใช้สามารถล็อกอินหรือสมัครด้วยวิธีตามขั้นตอนในระบบ โดยจะมี
   1.1 การล็อกอินด้วย LINE
       - เพื่อผู้ใช้ที่ต้องการเห็นความคืบหน้าและแจ้งเตือนโดยอัตโนมัติ
   1.2 การสมัคร/ล็อกอินด้วยการกรอก ชื่อ ตำแหน่ง ประจำสาขา
       - เพื่อใช้งานในเบื้องต้น แต่จะไม่มีการแจ้งเตือน
   1.3 การเข้าใช้งานด้วย Key Pass
       - เป็นการนำ Key Pass ที่สมัครด้วยขั้นตอน 1.2 มาใช้งานบนเบราว์เซอร์อื่น
         ได้เพื่อความยืดหยุ่น และจะกู้ข้อมูลระบบเดิมทันที

ข้อควรระวังเมื่อท่านมาใช้งานในระบบแจ้งซ่อม
   - ต้องมีตัวตนจริงภายในองค์กร

ประโยชน์ของระบบ
   - ระบบนี้สร้างมาเพื่อสำหรับการแจ้งซ่อมให้ IT รับทราบผ่านระบบในไม่กี่ขั้นตอน
   - เพื่อความสะดวกของพนักงานในเวลาที่ไม่สามารถติดต่อ IT ได้ในเวลานั้น
   - พนักงานจะทราบข้อมูลการเคลื่อนไหวของไอทีแบบเรียลไทม์

* หากมีงานด่วนมากๆ สามารถติดต่อได้โดยการโทรหรือทักแชทไลน์ได้ปกติ *
